# Logo Perusahaan & Hero Image

## Logo Perusahaan
Silakan simpan file logo perusahaan di folder ini dengan nama:
- `logo.png` (format PNG)
- atau `logo.jpg` (format JPG)

Logo akan otomatis digunakan di:
- Navbar (header website)
- Footer
- Admin Panel Sidebar

## Hero Image (Homepage)
Silakan simpan gambar hero untuk homepage di folder ini dengan nama:
- `hero-image.jpg` (format JPG)
- atau `hero-image.png` (format PNG)

Gambar hero akan otomatis digunakan di:
- Hero Section (bagian atas homepage)

**Catatan:** 
- Format yang didukung: PNG atau JPG
- Nama file harus tepat: `logo.png`/`logo.jpg` atau `hero-image.png`/`hero-image.jpg`
- File akan otomatis terdeteksi setelah disimpan
